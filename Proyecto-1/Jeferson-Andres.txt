📝 Descripción de la Tarea¡Hola, equipo de desarrolladores! 👋
En esta tarea, pondrán en práctica sus habilidades en HTML, PHP, MySQL y Tailwind para crear un software que cumpla con los requerimientos específicos del SENA. El objetivo es desarrollar una aplicación web que permita gestionar las asistencias de los aprendices de manera eficiente, intuitiva y segura.

El software debe seguir Programación Orientada a Objetos (POO) y el patrón de diseño Singleton. Además, trabajarán utilizando metodologías ágiles como Scrum y Kanban para organizarse y cumplir con el tiempo límite de 5 horas. ¡No se desvíen de los requerimientos! 🚨

🎯 Requerimientos del Software
El sistema debe cumplir con las siguientes características:

1. Estructura del SENA 🌍
El SENA tiene regionales.
Cada regional tiene centros.
Cada centro tiene un super administrador que crea coordinadores.
2. Funcionalidades del Coordinador 👨‍💼
Crear programas de formación.
Crear ambientes (aulas, talleres, etc.).
Crear fichas (grupos de aprendices).
Crear instructores.
3. Funcionalidades del Instructor 👩‍🏫
Tomar lista de asistencia de las fichas asignadas.
La interfaz debe ser muy intuitiva y permitir tomar lista con el mínimo de clics posible.
4. Seguridad y Permisos 🔒
Debe existir un sistema de login y registro (el registro lo hace el super administrador o coordinador).
Cada usuario debe tener permisos específicos según su rol.
5. Reportes de Asistencias 📊
El sistema debe mostrar reportes individualizados de los aprendices que tengan más de 3 faltas.
6. Interfaz de Usuario 🎨
La interfaz debe ser fácil de usar para todos los usuarios (super administradores, coordinadores e instructores).
Utilicen Tailwind CSS para diseñar una interfaz moderna y responsive.
🛠️ Tecnologías a Utilizar
Frontend: HTML + Tailwind CSS.
Backend: PHP.
Base de Datos: MySQL.
Paradigma: Programación Orientada a Objetos (POO).
Patrón de Diseño: Singleton.
⏰ Tiempo de Desarrollo
Duración máxima: 5 horas. ⏳
Modalidad: Trabajo en equipo. 👥
🌀 Organización del Equipo (Jerarquía y Roles)
Para optimizar el tiempo y asegurar una colaboración efectiva, asignen los siguientes roles en el equipo:
1. Scrum Master 🧙‍♂️
Responsable de guiar al equipo en la metodología Scrum.
Asegura que se sigan las reuniones diarias (Daily Standups) y se cumplan los tiempos.
2. Product Owner 📋
Representa al "cliente" (en este caso, el SENA).
Define las prioridades de las tareas y asegura que el equipo cumpla con los requerimientos.
3. Desarrolladores 👩‍💻👨‍💻
Encargados de codificar el proyecto.
Se dividen las tareas según el tablero Kanban.
4. Diseñador de Interfaz 🎨
Responsable de crear una interfaz intuitiva y atractiva usando Tailwind CSS.
5. Tester 🧪
Verifica que todas las funcionalidades funcionen correctamente antes de la entrega.
📊 Metodologías Ágiles: Scrum y Kanban
1. Scrum 🔄
Realicen una reunión inicial (Sprint Planning) para dividir las tareas y asignar responsabilidades.
Hagan Daily Standups (reuniones cortas de 5 minutos) para revisar el progreso y los obstáculos.
Al final, hagan una revisión (Sprint Review) para verificar que todo esté listo.
2. Kanban 📌
Utilicen un tablero Kanban (puede ser físico o digital, como Trello o GitHub Projects).
Dividan las tareas en columnas: Por hacer, En progreso y Terminado.
Muevan las tareas según su estado para visualizar el progreso.
✅ Criterios de Evaluación
Cumplimiento de Requerimientos: El software debe cumplir con todas las características solicitadas.
Calidad del Código: Uso correcto de POO y Singleton.
Diseño de Interfaz: La interfaz debe ser intuitiva y atractiva.
Funcionalidad: El sistema debe funcionar sin errores.
Trabajo en Equipo: Demostrar colaboración y distribución de tareas.
Uso de Metodologías Ágiles: Evidencia de la aplicación de Scrum y Kanban.
